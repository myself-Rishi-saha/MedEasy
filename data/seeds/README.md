# Demo seed data

All names, phone numbers, addresses, emails, SKUs, references, and transactions are fictional. Email addresses use the reserved `.test` domain. Sample GST rates are configurable demonstration values only and are not authoritative tax advice. Seed user profiles contain no passwords or password hashes. JSON-backed authentication stores password hashes, opaque session-token hashes, and one-time account-setup verification-token hashes in the runtime `accounts.json`, `sessions.json`, and `verifications.json` collections; never commit runtime credentials or tokens.
